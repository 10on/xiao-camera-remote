# Display wiring — способ A vs способ B

Дисплей и библиотека одинаковые в обоих случаях: Waveshare 1.5" 240×280,
`Adafruit GFX Library@^1.12.6` + `Adafruit ST7735 and ST7789 Library@^1.11.0`
+ `Adafruit BusIO@^1.17.2`.

| Сигнал | Способ A (работает) | Способ B (не работает) |
|---|---|---|
| DIN (MOSI) | D10 | D8 |
| CLK (SCK)  | D8  | D6 |
| DC         | D6  | D0 |
| CS         | GND напрямую | D1 (GPIO) |
| RST        | не подключен (soft reset) | D10 (GPIO), ранее — PCF8575 P10 |
| BL         | 3.3V напрямую | 3.3V напрямую |

Способ B прозвонен мультиметром пин в пин по этой таблице — распайка
подтверждена физически, картинки всё равно не было.
